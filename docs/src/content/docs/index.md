---
title: playground-cc
description: A browser-based C playground for learning and teaching C.
---

playground-cc runs C programs in the browser, with no backend. It is meant for
people learning C and for those who teach it.

**Documented release: none yet.** These docs describe only what has been
released. The first release is 0.1.

- [Guide](guide/): using the playground.
- [Development](development/): building, testing and hosting it.
