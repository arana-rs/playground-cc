title: playground-cc
description: Un entorno de C en el navegador para aprender y enseñar C.
---

playground-cc ejecuta programas en C en el navegador, sin backend. Está pensado
para quienes aprenden C y para quienes lo enseñan.

**Versión documentada: ninguna todavía.** Esta documentación describe solo lo
que se ha publicado. La primera versión será la 0.1.

- [Guía](guide/): uso del playground.
- [Desarrollo](development/): compilarlo, probarlo y alojarlo.
